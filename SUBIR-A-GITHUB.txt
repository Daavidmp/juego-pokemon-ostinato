ANTES DE SUBIR — público o privado
----------------------------------
El proyecto lleva dentro tiles, sprites, música y sonidos de Pokémon. Nintendo
cierra repositorios de fangames con cierta regularidad, y el aviso llega a
nombre de la cuenta, no del proyecto.

Si el repositorio es para guardar tu trabajo y no perderlo, ponlo PRIVADO:

    En GitHub: Settings -> General -> Danger Zone -> Change visibility

En privado tienes exactamente lo mismo sin exponerte. Público no te aporta nada
todavía. Si aun así lo quieres abierto, adelante, pero que sea una decisión.


SUBIRLO
-------
Abre una consola NUEVA (la que hubiera abierta antes de instalar git no
encuentra el comando) y ejecuta:

    cd "C:\Users\ASUS\Music\Pokemon Ostinato"
    git push -u origin main

Tarda. Son unos 448 MB y va a parecer que se ha colgado varias veces. No lo
cortes.

Te va a pedir que inicies sesión. Se abre una ventana del navegador y lo
autorizas ahí; no hace falta token ni contraseña.


A PARTIR DE AHORA
-----------------
Cada vez que quieras guardar cambios:

    cd "C:\Users\ASUS\Music\Pokemon Ostinato"
    git add .
    git commit -m "lo que hayas hecho"
    git push

Para ver qué has tocado desde el último guardado:

    git status

SOBRE EL PESO
-------------
448 MB, y la mitad son secuencias de fotogramas:

  Graphics/Titles/OstinatoCine/    4811 JPEG   143 MB   la cinemática
  Graphics/Titles/OstinatoMenu/     400 JPEG   105 MB   el fondo del menú
  Graphics/Titles/OstinatoIntro/    160 JPEG    11 MB   el vídeo de marca

Git no lleva bien miles de binarios: cada vez que cambie uno guarda el archivo
entero otra vez, así que el repositorio solo puede crecer. De momento entra sin
problema, pero si se vuelve lento, en el .gitignore están esas tres líneas
preparadas para descomentar. Ojo: el juego NO arranca sin ellas, así que habría
que guardar los vídeos originales aparte y dejar apuntado de dónde salen.
