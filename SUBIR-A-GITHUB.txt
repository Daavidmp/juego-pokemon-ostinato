SUBIR POKÉMON OSTINATO A GITHUB
===============================

PASO 0 — Instalar git (no lo tienes)
------------------------------------
He comprobado el equipo y git no está instalado, así que los comandos de
GitHub no te van a funcionar todavía. Bájalo de:

    https://git-scm.com/download/win

Instalador siguiente-siguiente, todo por defecto. Cuando acabe, CIERRA y vuelve
a abrir la consola (si no, no encuentra el comando) y comprueba:

    git --version


PASO 1 — Decidir si el repositorio es público o privado
-------------------------------------------------------
LÉELO ANTES DE SUBIR.

El proyecto lleva dentro tiles, sprites, música y sonidos de Pokémon. Nintendo
cierra repositorios de fangames con cierta regularidad, y el aviso llega a
nombre de la cuenta, no del proyecto.

Si el repositorio es para guardar tu trabajo y no perderlo, ponlo PRIVADO.
Hacerlo público no te aporta nada ahora mismo y te expone.

    En GitHub: Settings -> General -> Danger Zone -> Change visibility

Si lo quieres público de todas formas, allá tú, pero que sea una decisión y no
un descuido.


PASO 2 — Subirlo
----------------
Abre la consola EN LA CARPETA DEL PROYECTO:

    cd "C:\Users\ASUS\Music\Pokemon Ostinato"

Y ejecuta, una a una:

    git init
    git add .
    git commit -m "Primer commit: Pokemon Ostinato"
    git branch -M main
    git remote add origin https://github.com/Daavidmp/juego-pokemon-ostinato.git
    git push -u origin main

El primer `git add .` tarda un rato: son 22.000 archivos. El `push` tarda más
todavía, porque sube unos 490 MB. Déjalo correr y no lo cortes.

Si te pide usuario y contraseña, la contraseña NO es la de tu cuenta: hace
falta un token. GitHub te lo ofrece solo la primera vez, o lo sacas en
Settings -> Developer settings -> Personal access tokens.


LO QUE NO SE SUBE
-----------------
El .gitignore de la raíz deja fuera:

  *.bak, *.bak-*     las copias de seguridad del motor (tu red para deshacer;
                     se quedan en el disco, pero versionarlas no tiene sentido)
  Game.rxdata        TU partida guardada. Si se sube, quien clone el repo
                     empieza con tus Pokémon
  *.log, *.dmp       registros de errores
  *.kra~             los respaldos que deja Krita
  Thumbs.db          basura de Windows


SOBRE EL PESO
-------------
Unos 490 MB, y la mitad son secuencias de fotogramas:

  Graphics/Titles/OstinatoCine/    4811 JPEG   143 MB   la cinemática
  Graphics/Titles/OstinatoMenu/     400 JPEG   105 MB   el fondo del menú
  Graphics/Titles/OstinatoIntro/    160 JPEG    11 MB   el vídeo de marca

Git no lleva bien miles de binarios: cada vez que cambie uno guarda el archivo
entero otra vez, así que el repositorio solo puede crecer. De momento entra sin
problema, pero si se vuelve lento, en el .gitignore están esas tres líneas
preparadas para descomentar. Ojo: el juego NO arranca sin ellas, así que habría
que guardar los vídeos originales aparte y dejar apuntado de dónde salen.
